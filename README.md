# 01. Título & Descrição Curta 
**Calculadora da Fórmula de Bhaskara**

Aplicação em Python para fazer o cálculo da fórmula de Bhaskara.

## 02. Tecnologias Utilizadas
- Python 3.14

## 03. Como Instalar e Executar
Executar através de **IDEs** instaladas na sua máquina ou de compiladores on-line, como o [myCompiler.io](https://www.mycompiler.io/pt).

## 04. Exemplo de Uso ou Demonstração
Utilizando como exemplo, os valores A = 2, B = 12, C = -14.
```
Informe o número A: 2

Informe o número B: 12

Informe o número C: -14

O valor de X' é =  1.0

O valor de X" é =  -7.0
```
